# BookTracker

Android-приложение для **трекинга книг** с дашбордами и распознаванием цитат с фотографии страницы (OCR).

## Возможности

- 📚 **Библиотека книг** — добавление книг с обложкой, автором, статусом (хочу прочитать / читаю / прочитано), оценкой и заметками.
- 📈 **Прогресс чтения** — отметка текущей страницы; статус и серия чтения обновляются автоматически.
- 📊 **Дашборд** — статистика: прочитано книг, страниц за 14 дней, книги по месяцам, распределение оценок, серия дней чтения, число цитат.
- 📷 **Цитаты с фото** — сфотографируйте страницу (или выберите фото из галереи), приложение распознает текст (**русский + английский**, офлайн через Tesseract) и сохранит как цитату, привязанную к книге. Текст можно отредактировать перед сохранением.

## Стек

- Kotlin + Jetpack Compose (Material 3)
- Room (локальная база данных)
- Tesseract4Android (офлайн OCR; языковые данные `rus`/`eng` докачиваются при первом распознавании)
- Coil (изображения), Navigation Compose

## Сборка

### Через GitHub Actions (рекомендуется)
При пуше в любую ветку запускается workflow `Build BookTracker APK`. Готовый `app-debug.apk`
скачивается из артефактов сборки (вкладка **Actions** → нужный run → **Artifacts** → `booktracker-debug-apk`).

### Локально
Нужен Android SDK (Android Studio).
```bash
cd booktracker
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Требования

- Android 7.0 (API 24) и выше.
- Для первого распознавания цитаты нужен интернет — приложение один раз скачивает
  языковые данные Tesseract (~несколько МБ). Дальше OCR работает офлайн.
