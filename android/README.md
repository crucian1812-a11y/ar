# Бодо Бородо — Путешествие за буквами 🧔🌍

Образовательная Android-игра для детей про **русские буквы**, в стиле тёплого
мультика-путешествия. Главный герой — бородатый путешественник **Бодо Бородо**
(оригинальный персонаж, нарисован векторно «по мотивам»).

Игра — это **бродилка по карте** из 6 этапов-квестов (по числу серий-вдохновений)
с вопросами и мини-играми. Работает **полностью офлайн**, без интернета.

## 🗺️ Уровни

Путешествие из 6 этапов: **2 раунда про буквы** + аркадные мини-игры.

| № | Этап | Тип | Что делаем |
|---|------|-----|------------|
| 1 | 🌼 Полянка Букв | буквы | С какой буквы начинается слово (картинка → буква) |
| 2 | 🎈 Воздушный Шар | аркада | Летим на шаре: тап — вверх, собираем ⭐, уклоняемся от туч |
| 3 | 🚂 Поезд Слогов | буквы | Собрать слово из букв по порядку |
| 4 | ⛰️ Горная Тропа | аркада | Бег с прыжками: тап — прыжок через камни, собираем 🍎 |
| 5 | 🌊 Морская Ловля | аркада | Двигаем Бодо пальцем, ловим рыбу/сокровища, избегаем бомб |
| 6 | 🎉 Праздник Друзей | аркада | Финальная ловля шариков и сладостей |

За каждый уровень — до ⭐⭐⭐ (без ошибок/попаданий = 3 звезды). Прогресс
сохраняется на устройстве. Управление — касанием (тап и перетаскивание),
поддерживается портрет и ландшафт.

Персонаж **Бодо** перерисован по референсу: оранжевое «бородатое» тело-купол,
голубая маска-лицо с большими глазами и бровями, волнистый рот, голубые ручки
и ножки, разные эмоции (спокойный / радостный / смех).

## 📦 Как получить готовый APK

APK собирается автоматически в **GitHub Actions** (в этой песочнице нет доступа
к серверам Google/Gradle, поэтому сборка идёт в облаке GitHub):

1. Открой вкладку **Actions** в репозитории → workflow **Build APK**.
2. Дождись зелёной галочки на запуске для своей ветки.
3. Внизу страницы запуска скачай артефакт **`BodoBorodo-apk`** → внутри `BodoBorodo.apk`.
4. Перекинь файл на Android и установи (разреши «Установка из неизвестных
   источников»). Это debug-сборка, специально для проверки/сайдлоада.

Запустить сборку вручную можно кнопкой **Run workflow** (`workflow_dispatch`).

## 🛠️ Локальная сборка (если есть Android SDK)

```bash
cd android
./gradlew assembleDebug
# результат: app/build/outputs/apk/debug/app-debug.apk
```

Требуется JDK 17, Android SDK (platform `android-34`, build-tools `34.0.0`).

## ⚠️ Важно про мультфильм

«Бодо Бородо» — существующий мультсериал. Точную копию его персонажа
воспроизводить нельзя по авторским правам, а сами ролики с YouTube из среды
разработки недоступны. Поэтому персонаж и уровни сделаны **оригинально, по
мотивам** общей идеи (путешествия + изучение букв), а не как копия конкретных
серий. Контент легко расширить/заменить в `game.js` (массив `LEVELS`).
