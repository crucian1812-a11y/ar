# Витязи Новгорода

Аркадная игра-битва для Android: витязь обороняет древний Новгород от набега.
Нативный **Kotlin + SurfaceView** (свой игровой цикл), без внешних движков.
Вся графика рисуется процедурно на Canvas в едином стилизованном стиле.

## Геймплей

- **4 уровня** со сменой сцен и нарастающей сложностью:
  1. **Стены Детинца** (рассвет) — налётчики
  2. **Новгородский торг** (день) — налётчики + лучники
  3. **Мост через Волхов** (закат) — лучники + тяжёлые враги
  4. **Враг у Святой Софии** (ночь) — **босс-воевода**
- Бой на мечах, прыжки и уклонения от стрел (стрелы можно **отбивать** мечом),
  комбо за серию ударов, очки, полоски здоровья и боссфайт.

## Управление (сенсор)

- **◀ ▶** — движение
- **⤒** — прыжок
- **⚔** — удар мечом

## Сборка APK

### GitHub Actions (рекомендуется)
Workflow `Build Vityazi APK` собирает `app-debug.apk` при пуше в `vityazi/**`.
Скачать: вкладка **Actions** → нужный run → **Artifacts** → `vityazi-debug-apk`.

### Локально
```bash
cd vityazi
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Требования
Android 7.0 (API 24)+. Игра запускается в горизонтальной ориентации, полноэкранно.
