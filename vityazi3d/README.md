# Витязи: Открытый мир (3D)

Прототип 3D-игры с **открытым миром** на движке **Godot 4**. Витязь от третьего
лица свободно ходит по холмистому миру; на него волнами набегают враги.
Вся геометрия — **процедурная и низкополигональная** (генерируется кодом),
без бинарных арт-ассетов.

## Что есть в прототипе

- Процедурный ландшафт из шума (холмы, вода, центральная поляна)
- Лес и новгородские постройки (храм с золотым куполом, башни, избы)
- Управление от 3-го лица: виртуальный джойстик + поворот камеры пальцем
- Бой мечом, прыжок, волны врагов, счётчик повергнутых и здоровье
- Динамическое небо, солнце, туман

## Управление (сенсор)

- **Левая половина экрана** — перетаскивание = движение (виртуальный джойстик)
- **Правая половина** — перетаскивание = поворот камеры
- **⚔** (справа внизу) — удар мечом
- **▲** — прыжок

## Сборка APK

Workflow `Build Vityazi 3D APK` собирает APK при пуше в `vityazi3d/**`.
Скачать: **Actions** → нужный run → **Artifacts** → `vityazi3d-debug-apk`.

Сборка в CI: ставит Godot 4.3 headless + export-templates + Android SDK,
генерирует debug-keystore и экспортирует APK (`--export-debug "Android"`).

## Заметки

Это **фундамент** для более крупной 3D-игры. Дальше можно добавить:
стриминг чанков мира, нормальные модели/анимации (CC0-паки), боссов,
квесты, день/ночь, звук.
